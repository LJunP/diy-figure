# DIY 定制盲盒手办平台

面向个人用户的 AI 对话式手办/盲盒定制平台。用户通过与 AI 对话（文字/图片/文件输入）实时生成原创角色设计，平台负责报价、生产对接与发货，最终交付实体定制手办盲盒。


## 核心流程

```
注册登录
  → 创建系列（自命名，选规格档位 + 尺寸档位）
  → 系列内创建多个画布（每个画布 = 一个原创角色的 AI 对话式设计）
  → 画布逐个定稿（不允许模仿真实明星/已有 IP 角色）
  → 凑够档位要求数量 → 提交报价申请（触发人工终审）
  → 终审通过 → 报价 + 预计交期反馈
  → 用户接受 → 抽奖（按比例抽中，如 12 选 8）
  → 强制填写收货地址 + 支付定金（50%）→ 设计锁定，不可再改
  → 联系厂家生产 → 货到平台质检
  → 支付尾款（50%）→ 平台转发发货
  → 用户签收
  → 未中签角色 60 天内可按溢价补购（套餐总价 ÷ 中签数量 × 1.3）
```

## 规格档位

| 档位 | 设计数量 | 定制数量 | 未中签（可补购） |
|---|---|---|---|
| 轻量系列 | 6 | 4 | 2 |
| 经典系列 | 9 | 6 | 3 |
| 收藏系列 | 12 | 8 | 4 |

尺寸档位对应不同大小的包装盒，所有包装盒外观统一设计，仅大小有区别。

## 关键业务规则

- **合规红线**：禁止设计模仿真实明星/公众人物/已有版权 IP 角色。采用 AI 自审（system prompt 约束）+ 人工终审（提交报价前，终审判定侵权必须拒绝）双重拦截，免责声明仅作兜底补充条款，不作为主防线。
- **付款节点**：定金 50%（接受报价+抽奖后支付，同时锁定设计）；尾款 50%（厂家生产完成、平台质检通过后支付，收到尾款才发货）。
- **违约金**：未付定金前取消无损失；已付定金未开始生产取消扣除部分定金作为服务费；已进入生产阶段取消定金不退。
- **通知渠道**：站内消息全量覆盖；邮件仅在报价确认、需付尾款、已发货三个关键节点同步。

## 技术方向（待 03-技术设计说明书 定稿）

- AI 对话与设计：GPT-4o（多模态对话，接收文字/图片/文件）
- 2D 概念图生成：DALL-E 3 / Flux.1
- 3D 参考模型生成：Meshy AI / Tripo3D（供厂家原型师精修参考，非直接可打印文件）
- 支付：微信支付 + 支付宝（国内），国际化支付（Stripe）延后至后续迭代
- 首版不做国际发货
